# 常见问题

## 双击后没有打开网页

确认已安装 Python 3.10+，并从完整解压目录运行启动脚本。启动窗口出现错误时先读完提示，不要立即关闭。也可以在 App 文件夹打开终端运行 `python3 start.py`；Windows 可以试 `py -3 start.py`。服务启动后手动打开 `http://127.0.0.1:8765`。

## 提示 8765 端口被占用

通常是之前启动的 App 窗口仍在运行。切回该窗口按 `Ctrl+C`，再重新启动。App 固定使用本机端口，不会悄悄改到别的地址。

## Python 命令找不到

Windows 在 PowerShell 试 `py -3 --version`，macOS 在终端试 `python3 --version`。若没有 Python，使用 [Python 官方下载页](https://www.python.org/downloads/)安装。Windows 安装时可选将 Python 加入 PATH。

## 如何恢复之前的答案

打开后先填写与之前完全相同的姓名和学号。恢复需要使用同一台电脑、同一份解压目录；复制或重新解压 App 会产生另一份 `提交资料/`。

## 为什么修改后显示“有修改”

每题都要手动点击“提交本题”。未提交草稿只保留在当前页面；切换题目不会自动保存，刷新或关闭页面前请先提交。提交失败时检查启动窗口、App 文件夹权限和磁盘空间，然后重试。

## 附件被拒绝或太大

每题的允许格式不同，请按题目页的说明选择文件。单文件不能超过 50 MB。大型项目优先填写 GitHub 仓库链接；项目题也接受 ZIP。被拒绝的附件不会替换已有答案。

## App 会检查附件里的密钥吗？

不会完整扫描。页面只对答案文本和 `.txt` / `.md` 附件做简单的本机特征提示，可能漏报或误报。PDF、DOCX、XLSX、图片和 ZIP 内容不会被读取或检查。上传前请逐个自行检查；截图要把密钥打码。

## 外链离线打不开

这是预期情况。题目、讲义和本地保存不依赖网络；Bilibili、GitHub、Claude Code 等外部页面需要网络。

## 我必须安装 Node.js 吗？

不必。Node.js/npm 仅用于开发者重新构建网页，或选择 npm 安装某些 Agent 的路线。运行本 App 只要求 Python 3.10+。

## 我在哪里找到并提交资料？

右侧“提交文件”目录树会显示自动生成文件和已提交文件；点击“打开文件夹”可在 Finder/文件资源管理器中查看。目录为 `提交资料/姓名_学号/`，每题一个文件夹。逐题检查并提交后，只压缩自己的个人目录，确认没有密钥和私人内容，再按组织者通知的地址用 QQ 邮箱发送。App 不会自动发送。
